# AutoCAD DXF Exporter

Скрипт для извлечения данных из DXF файлов и экспорта в JSON/CSV/Excel.

## 🚀 Возможности

- Чтение DXF файлов любой версии
- Поиск и извлечение блоков с атрибутами
- Экспорт в JSON, CSV и Excel форматы
- Анализ и статистика данных
- Визуализация расположения блоков
- Веб-интерфейс для просмотра
